# Artwork

- `observatory.png`: original fantasy matte painting generated with OpenAI image generation for this application, October 2026. Prompt direction: charcoal valley, warm bronze observatory, misty mountains, quiet negative space, no game-derived assets or lettering. Bundled unchanged from the generated source.
- `app.svg`: original vector compass/signal emblem. `app.ico` contains 16, 24, 32, 48, 64, 128, and 256 px renders for Windows. Re-export from the SVG when changing branding.
- Country flags, activity symbols, membership stars, pin, and gear are drawn as vectors in WPF; no network asset downloads are required.

These project-created assets are included under the repository's Apache 2.0 license. They do not include Jagex game artwork.
