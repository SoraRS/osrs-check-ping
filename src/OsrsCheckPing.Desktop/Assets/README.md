# Artwork

- `observatory.png`: original fantasy matte painting generated with OpenAI image generation for this application, October 2026. Bundled unchanged from the generated source.
- `app.svg`: original vector compass/signal emblem. `app.ico` contains multiple resolutions for Windows; WPF uses a vector drawing of the same emblem.
- Country flags, fallback activity symbols, membership stars, tracking power icon, heart, and gear are drawn as vectors in WPF.
- `Osrs/`: unmodified OSRS skill and boss sprites, including the native total-level experience graph. See [sprite sources and credits](Osrs/SOURCES.md). These third-party images are copyright Jagex Ltd., rather than project-created Apache-licensed artwork.

Project-created artwork is covered by the repository's Apache 2.0 license. All artwork is bundled locally; there are no runtime image downloads.
