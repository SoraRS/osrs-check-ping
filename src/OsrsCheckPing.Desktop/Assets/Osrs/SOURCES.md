# OSRS sprite sources

These are unmodified Old School RuneScape sprites, copyright Jagex Ltd., distributed here for identification of worlds and activities. They are third-party game artwork and are not covered by this repository's Apache 2.0 license. This independent utility is not affiliated with Jagex.

Skill sprites were obtained from RuneLite's published resources at revision `e98399f931c60bfa8e42f924da850f508ec8e00d`; boss/activity sprites were obtained from the OSRS Wiki. The files are bundled locally; the running app does not download artwork.
