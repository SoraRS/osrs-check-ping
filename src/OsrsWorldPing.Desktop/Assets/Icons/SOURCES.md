# Profile icons

The About page uses vector paths from these bundled originals:

- GitHub mark: [Primer Octicons](https://github.com/primer/octicons/blob/main/icons/mark-github-16.svg), [MIT license](LICENSE-Octicons.txt).
- Discord mark: [Simple Icons](https://github.com/simple-icons/simple-icons/blob/develop/icons/discord.svg), [CC0 license](LICENSE-SimpleIcons.txt).

The marks identify external profile links; they do not imply endorsement. SVGs and license notices are bundled with the executable. The app does not fetch icons at runtime.
